Error States — Mobile Notes

  • 3 representative errors shown here: DOWNLOAD_BLOCKED, DOWNLOAD_AGE_RESTRICTED, INTERNAL_ERROR.
  • All 9 error codes use identical card structure — only icon + message + next steps change.
  • Error cards appear INLINE on the Progress screen below the failed stage.
  • CTAs are 44px tall — full mobile touch target compliance.
  • Primary CTA: retry / try new URL (most common actions). Full width when one CTA.
  • Secondary CTA: 50/50 split with primary when two actions available.
  • No stack traces, no error codes in user-facing message text (code shown in label only).
  • INTERNAL_ERROR: deliberately vague. Logged server-side, never detailed to user.
  • Back link top-right → Submit screen (start fresh).
