Job history stored locally · 7-day TTL stem-loops.com

Desktop Layout

  • Table format for desktop — more scannable than card list
  • Columns: video title, stems, bars, loop count, date, status, actions
  • Filter tabs by status. Search box for title lookup.
  • Sort: newest first (default) or by status
  • Table rows hover state: subtle background highlight

Anonymous History Mechanism

  • Primary: localStorage stores array of {jobId, title, params, status, created}
  • Secondary: signed cookie from server (survives localStorage clear, cross-tab)
  • On first job creation: server sets signed cookie with job IDs
  • Cookie is signed (HMAC), not encrypted — tamper-evident, not private
  • "Clear all": deletes localStorage + sends cookie clear request to server

Expiry & TTL Handling

  • All jobs expire at 7 days (PRD §4.4). R2 objects also expire via lifecycle rule.
  • Warning shown when < 24h remaining: date text turns red, advisory note
  • After expiry: row still shows but "View loops" → expired link message
  • Cleanup: front-end removes expired entries from localStorage on load
  • DB cleanup: server cron hard-deletes expired jobs (TSD T33)
