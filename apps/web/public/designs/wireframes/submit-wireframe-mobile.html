Design Notes — Submit · Mobile

  • Single-column stacked layout. No sidebar. Zero decoration.
  • URL input is the hero — largest interactive element on screen.
  • Stem chips use 2-column grid → comfortable 44px touch targets.
  • Loop length uses 4-up segmented selector across full width.
  • History link top-right: minimal, not competing with primary CTA.
  • Submit CTA disabled until URL + ≥1 stem selected (zod validation).
  • No decorative imagery, no hero illustration — tool-first aesthetic.
  • Dark background (#111) reflects DAW dark-mode context.
