Two-Column Results Layout

  • Sidebar (240px): filters by stem / section / energy + sort control
  • Content: loop pack ZIP CTA at top, then 2-col card grid
  • Sidebar filter state updates grid in real-time (client-side)
  • All filter counts reflect the current job's loop distribution

Loop Card Anatomy

  • Waveform: 80px tall, wavesurfer.js rendering pre-computed peaks
  • Playhead: animated while playing, draggable for scrubbing
  • Section markers: vertical lines at section boundary time offsets
  • 5 tags: stem (prominent), BPM, key, section, energy
  • Drag handle: draggable file via HTML5 drag API → DAW accepts as .wav

Waveform Design

  • Pre-computed peaks stored in loops.waveform_peaks (jsonb)
  • wavesurfer.js renders peaks client-side — no re-decode needed
  • Section markers drawn as overlaid vertical lines on waveform
  • Playhead visible while playing; scrub to any position
  • Duration label bottom-right of waveform

Download & Drag Interactions

  • Download WAV: direct R2 signed URL (7-day). Single loop.
  • Download ZIP: JSZip client-side, assembles all visible loops
  • Drag handle: HTML5 draggable with .wav MIME type
  • DAW (Ableton/FL/Logic) accepts drag from browser as audio file
  • Tooltip on drag handle: "Drag into your DAW"
