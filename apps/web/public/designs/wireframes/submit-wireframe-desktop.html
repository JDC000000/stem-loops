Layout Decisions

  • Centered single-column card (720px wide) on 1440px canvas
  • Nav: logo + tagline left / "my jobs" right. No menus.
  • Hero headline + sub above form card
  • Stems + loop-length side-by-side on desktop (collapses to stacked on mobile)
  • Recent jobs strip below form (conditional on history)

Interaction Notes

  • Submit CTA disabled until URL valid + ≥1 stem selected
  • URL input: inline validation on blur or paste
  • Stems: multi-select checkboxes. Select all / clear helpers.
  • Loop length: single-select radio behavior (only one at a time)
  • On submit: loading state → navigate to /jobs/[id] (progress page)

Design Principles Applied

  • Dark-mode first — background #111 matches DAW aesthetic
  • Zero decorative imagery. Form is the product.
  • No marketing copy beyond the tagline. Users know what stems are.
  • "my jobs" link: persistent, not modal. No account gates.
  • Footer: sparse. No newsletter, no social icons in V2.
