## ⚠️ Caveat (honest)
Measured on a **deterministic synthetic track** (`make_synthetic_fixtures.py`) with clean, abrupt section changes. This proves the heuristic **runs and detects boundaries correctly** — it is **not** a musical-quality verdict on real audio (real songs have gradual transitions, fills, drops). The dev box has no ffmpeg, so the fixture is WAV (detector is format-agnostic via librosa). Operator should re-run on a real labeled track and confirm labels feel musical at the gate.

## allin1 upgrade trigger (documented, NOT implemented in V2)
Upgrade to `allin1` if, in production, **≥20% of jobs return <5 loops/stem** OR users report "loops don't feel musical":
- Install `pip install allin1`; replace `detect_boundaries()` with `allin1.analyze()`.
- Cost: ~+200MB worker image, ~+3s latency/job. That footprint is why allin1 is deferred, not adopted now.
